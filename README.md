# Лабораторная работа 1.3

## Структура проекта

```
.
├── src/                          # Исходный код
│   ├── main.py                   # Точка входа (интерактивное меню)
│   ├── fibo_fact/                # Модуль: Фибоначчи и факториалы
│   │   ├── fibo.py               # Итеративное вычисление Фибоначчи
│   │   ├── fibo_recursive.py     # Рекурсивное вычисление Фибоначчи
│   │   ├── factorial.py          # Итеративный факториал
│   │   └── factorial_recursive.py # Рекурсивный факториал
│   ├── sort/                     # Модуль: Алгоритмы сортировки
│   │   ├── bubble_sort.py        # Сортировка пузырьком
│   │   ├── quick_sort.py         # Быстрая сортировка
│   │   ├── bucket_sort.py        # Блочная сортировка
│   │   ├── heap_sort.py          # Пирамидальная сортировка
│   │   ├── counting_sort.py      # Сортировка подсчетом
│   │   └── radix_sort.py         # Поразрядная сортировка
│   └── stack/                    # Модуль: Структура данных стек
│       └── stack.py              # Реализация стека
├── tests/                        # Unit тесты (pytest)
│   └── test_comprehensive.py     # Комплексные тесты всех модулей
├── pyproject.toml                # Конфигурация проекта
├── requirements.txt              # Зависимости
├── .pre-commit-config.yaml       # Автоматизация проверки кода
└── README.md                     # Этот файл
```

## Функциональность

### Математические функции
- **Факториал** (итеративный и рекурсивный)
- **Числа Фибоначчи** (итеративный и рекурсивный)

### Алгоритмы сортировки
- **Пузырьковая сортировка** (Bubble Sort)
- **Быстрая сортировка** (Quick Sort) 
- **Сортировка подсчетом** (Counting Sort)
- **Поразрядная сортировка** (Radix Sort)
- **Блочная сортировка** (Bucket Sort)
- **Пирамидальная сортировка** (Heap Sort)

**Важно:** Все алгоритмы сортировки работают только с целыми числами

### Структуры данных
- **Стек** на связном списке с поддержкой операций:
  - `push` - добавление элемента
  - `pop` - удаление и возврат верхнего элемента
  - `peek` - просмотр верхнего элемента
  - `is_empty` - проверка на пустоту
  - `__len__` - получение размера

## Запуск

1. Запустить приложение:
   ```bash
   python -m src.main
   ```

2. Запустить тесты:
   ```bash
   python -m pytest tests\
   ```
